Configurações

É aqui que você liga os avisos automáticos: o cliente recebe as confirmações no WhatsApp e você (dono) recebe os pedidos no Telegram. Sem configurar, o sistema fica em "modo simulado": registra tudo, mas não envia de verdade.

WhatsApp dos clientes (Evolution API)
Pedido confirmado, "saiu pra entrega" e "entregue" chegam sozinhos no WhatsApp de quem comprou.
Não configurado
Avisos por WhatsApp ativos
Desligado = não envia WhatsApp, mesmo com tudo configurado.

Você encontra a chave no painel da Evolution API (apikey). Ela fica guardada só no servidor.

O teste de conexão só confere se a instância está aberta. O teste real envia uma mensagem de verdade pro número acima — é a prova de que o cliente vai receber os avisos.

Como configurar

  1. Você precisa de um servidor Evolution API rodando (instalamos num VPS ou você contrata um provedor que ofereça Evolution pronta).
  2. No painel da Evolution, crie uma instância (sugestão de nome: acai-guri) e conecte o WhatsApp da loja lendo o QR Code com o celular — igual ao WhatsApp Web.
  3. Copie pra cá o endereço do servidor, a chave de API (apikey) e o nome da instância.
  4. Salve e teste a conexão. Depois, faça o teste real: informe um número de WhatsApp e envie a mensagem de teste — ela tem que chegar naquele celular.
  5. Pronto: confirmação, "saiu pra entrega" (com o código de entrega) e "entregue" chegam sozinhos pro cliente. A loja usa o número conectado na instância.

Vincular com código (o jeito seguro)

As notificações e os comandos vão somente pra conversa vinculada — quem só der "start" no bot não recebe nada e nenhum comando funciona pra essa pessoa. Pra vincular (ou trocar) a conversa do dono: gere o código aqui e, no seu Telegram, envie /vincular CÓDIGO na conversa com o bot. O código vale 10 minutos, serve uma única vez e é gerado um novo a cada clique.

Webhook protegido (produção)

Na loja publicada, o Telegram entrega os comandos por webhook. Registrando aqui, cada entrega vem assinada com um token secreto — POST falso sem a assinatura é recusado.

Como configurar

  1. No Telegram, converse com o @BotFather, envie /newbot, escolha nome e usuário do bot — ele devolve um token (uma sequência longa). Cole o token aqui.
  2. Abra o seu bot (link que o BotFather mostra), toque em Começar e mande um "oi".
  3. Vincule a sua conversa: aqui no painel, clique em Gerar código de vínculo e, na conversa com o bot, envie /vincular seguido do código (ex.: /vincular 123456). É esse código que garante que as notificações vão só pra você — dar "start" no bot não dá acesso a nada. (O botão Detectar meu chat continua servindo pra conferir o número da conversa.)
  4. Salve e teste: o botão de teste envia uma mensagem de verdade pro seu Telegram. Pedido novo passa a chegar com botões que acompanham o pedido até a entrega — ao tocar em Entregue, o bot pede o código de entrega (4 dígitos que estão com o cliente) e só confirma quando você digitar o código certo.

Como obter as credenciais

  1. A API da 99 é para empresas parceiras: peça o acesso na plataforma 99 Empresas (integração/API) — ou pelo e-mail api-suporte@99app.com. A 99 devolve Client ID, Client Secret e o Merchant ID da loja.
  2. A equipe da 99 retorna em até 2 dias úteis. A integração é voltada a empresas e um critério de volume de entregas pode se aplicar.
  3. Preencha os campos, confira o endereço de coleta, ligue as chamadas e salve. Use Testar credencial pra confirmar que a 99 aceitou.
  4. Com tudo ativo, o botão "Despachar pela 99" no pedido chama a API já com o PIN = código de entrega do pedido; o andamento aparece no histórico da entrega, no próprio detalhe.
  5. Enquanto as credenciais não vêm, nada muda na operação: o mesmo botão registra o despacho manual pra despachar pelo app da 99.
